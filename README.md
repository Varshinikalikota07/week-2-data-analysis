\# Week 2 Data Analysis Project



\## Overview

This project demonstrates SQL and Python techniques for data analysis.



\## Python Practice

1\. Load a CSV file and inspect dataset information.

2\. Identify and handle missing values.

3\. Detect and remove duplicate records.

4\. Calculate revenue and group it by category.

5\. Sort revenue and calculate a correlation matrix.



\## Tools Used

\- Python

\- Pandas

\- Google Colab

\- SQL



\## Dataset

The sample sales dataset contains order IDs, product categories, product names, quantities, and prices.



\## Results

\- Successfully inspected the dataset.

\- Filled missing values using column averages.

\- Removed duplicate records.

\- Calculated category-wise revenue.

\- Sorted sales and generated a correlation matrix.
